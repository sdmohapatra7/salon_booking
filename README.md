# Salon Booking Application

A full-stack salon booking application built with React, Node.js, Express, and PostgreSQL.

## 🚀 Live Demo
**Website / Frontend Live URL:** [https://salon-booking-silk-seven.vercel.app/](https://salon-booking-silk-seven.vercel.app/)

## 🏗 Stack details
* **Frontend:** React + Vite, Redux Toolkit, Tailwind CSS. Hosted on Vercel.
* **Backend:** Node.js, Express.js. Hosted on Render.
* **Database:** PostgreSQL (with Sequelize ORM). Hosted on Neon.
* **Authentication:** Google OAuth 2.0 & JWT

## 📂 Project Structure
- `/frontend` - Contains the React Vite client application.
- `/backend` - Contains the Node.js Express server.

## 🏃‍♂️ Running Locally

1. Create a PostgreSQL database and update `/backend/.env` with your credentials.
2. Inside `/backend`: Open terminal and run `npm install` then `npm start`
3. Inside `/frontend`: Open terminal and run `npm install` then `npm run dev`
